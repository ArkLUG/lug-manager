RSVP from Discord.

## New

- **"I'm going" on event announcements in Discord:** click to RSVP; click again to cancel. If the event is full you join the waitlist, and when someone cancels the next person moves up and gets a message. The reply is private to whoever clicked. Signup deadlines, cancelled and finished events work as on the site. Someone whose Discord account isn't linked to a member yet is told to sign in to LUG Manager with Discord once.
- **"View event" / "View meeting"** link buttons on announcements.
- **Settings > Discord > Buttons in Discord:** the public key that Discord signs button clicks with, with the setup steps (it used to be on the Discord matches page; a key already saved carries over).

Announcements posted before this version don't have the buttons.
