## Fixed

- **Display names:** signing in with Discord and the member sync no longer put a member's Discord name back over the display name made from their first and last name ("Ann B."). The Discord name is only used while we don't know their real name. On upgrade, display names that had been overwritten are rebuilt from first and last name once.
- **Dashboard on phones:** the profile card no longer cuts off the name and email: the name wraps, details stack, the "Edit my profile" button goes full width under them, and the paid-until date reads like the rest of the app.

## Upgrading from 2.0.10

No database migration. On first start, members with a first and last name get their display name rebuilt from them (logged as "[members] display names repaired ..."). Back up first as usual.
