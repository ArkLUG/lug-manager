# LUG Manager 2.0.7

Design tidy-up: plainer wording across the app.

## Changed

- Counts read naturally ("1 meeting", "3 events") instead of "meeting(s)", on the dashboard, members list and perk progress.
- Friendlier dates on the dashboard and members list.
- Section headings and buttons use sentence case (for example "Notification settings", "Add lead", "Edit my profile"). Page names in the sidebar are unchanged.
- Settings > Perks has plainer field labels ("Meetings needed", "Needs paid dues", "Order in the list").
- The "Members" button on a chapter page now matches the other secondary buttons.

## Upgrading from 2.0.6

Nothing to do; there are no database changes.
